# the-exorcist
The Exorcist
- A 2d horror game where you are an exorcist, taking on a mission to investigate the anomalies happen in a certain house in the middle of forest. Little did you know, the noble mission slowly escalates into a struggle for survival.

I built it using pygame library and the python language from scratch. Currently, the game is incomplete so it does not have an ending yet. The furthest I've made is the boss fight and you will likely be stuck there during playthrough.
I've just only worked on this project for 3 days so please excuse how low-quality it looks, but I will continue to polish it next week with actual gameplay I planned

How to play ?
WASD to move your character
